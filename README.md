# Shalikha Serbojonin Durga Mondir Website

একটি সাধারণ এবং আকর্ষনীয় ওয়েবসাইটের প্রজেক্ট যা শালিখা সর্বজনীন দুর্গোৎসবের জন্য তৈরি করা হয়েছে। এতে কাউন্টডাউন টাইমার, অনলাইন ইউজার কাউন্টার, ভাসমান ঢাকের শব্দ এবং গান শোনার প্লেয়ার যুক্ত আছে।

---

## 📌 ফিচারসমূহ (Features)

* **অনলাইন ভিজিটর কাউন্টার:** রিয়েল-টাইমে অ্যাক্টিভ ইউজার সংখ্যা আপডেট দেখায়।
* **লাইভ কাউন্টডাউন টাইমার:** মহালয়া এবং ষষ্ঠী পুজোর জন্য দিন, ঘন্টা, মিনিট এবং সেকেন্ডের সঠিক কাউন্টডাউন।
* **ভাসমান ঢাক আইকন:** স্ক্রিনের ডানপাশে ভাসমান ঢাক আইকনে ক্লিক করলেই ঢাকের শব্দ বাজা শুরু হবে।
* **অডিও প্লেয়ার / সং লিস্ট:** ওয়েবসাইটের নিচে সাজানো মিউজিক প্লেয়ারের মাধ্যমে যুক্ত করা গান শোনার সুযোগ।
* **ফেসবুক পেজ লিংক:** সরাসরি অফিশিয়াল ফেসবুক পেজে যাওয়ার বোতাম।
* **রেসপনসিভ ডিজাইন:** মোবাইল, ট্যাবলেট এবং কম্পিউটার—সব ডিভাইসেই সঠিকভাবে দেখতে পারার মত ডিজাইন।
